# `ad-lead-sync` Supabase Edge Function

This function is the only server-side bridge from the four approved Google
Sheet tabs to the canonical Supabase Lead/Outbox tables and Slack Lists.

Set these server-only Function Secrets before deployment:

```text
SUPABASE_SERVICE_ROLE_KEY
AD_LEAD_INGEST_HMAC_SECRET
SLACK_BOT_TOKEN
SLACK_LEAD_PIPELINE_LIST_ID
SLACK_LIST_COLUMN_MAP
SLACK_STATUS_OPTION_MAP
SLACK_OWNER_USER_MAP
```

The function uses `verify_jwt = false` because Google Apps Script is an
external service-to-service caller. It authenticates every request with the
timestamped HMAC headers generated by `AdLeadSync.gs`, rejects replays and
keeps an idempotency record in `ad_lead_sync_requests`.

Deploy after applying both canonical migrations. The five-minute Apps Script
request may contain no rows; the function must still claim and drain pending
CRM Outbox work.
